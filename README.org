#+TITLE: launcher.el

A macOS launcher for Emacs. Open apps, preview calculations, search the web,
and run custom tools from the minibuffer.

This is a fork of [[https://github.com/xiaoxinghu/launcher.el][xiaoxinghu/launcher.el]]. Thanks to Xiaoxing Hu for the original
project. This version has diverged substantially: apps, searches, and custom
actions now use the same tool interface, with live previews and native app icons.

[[file:assets/screenshot.png]]

* Install and launch

Install this fork with ~use-package~ and ~package-vc~:

#+begin_src emacs-lisp
(use-package launcher
  :vc (:url "https://github.com/tuyafeng/launcher.el"
       :branch "develop" :rev :newest)
  :bind ("C-c l" . launcher)
  :custom
  (launcher-app-discovery-method 'filesystem))
#+end_src

Alternatively, clone the repository and load it directly:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/launcher.el")
(require 'launcher)
(global-set-key (kbd "C-c l") #'launcher)
#+end_src

Include ~assets/launcher-icons.js~ when installing; it provides native app icons.
Launcher uses your existing completion UI and styles. Vertico, Orderless and
nerd-icons are optional.

| Command                         | What it does                     |
|---------------------------------+----------------------------------|
| ~M-x launcher~ / ~C-c l~        | Open the launcher                |
| ~M-x launcher-refresh~          | Refresh the app index            |
| ~M-x launcher-clear-icon-cache~ | Regenerate app icons on next use |

Type to see results, press ~RET~ to run the selected action, or ~C-g~ to cancel.
Blank input shows no results. With Vertico, ~TAB~ inserts the selected title or
tool prefix. With Emacs's default completion UI, it shows the available choices.

- ~emacs~ finds applications using your completion styles.
- ~1 + 2 * 3~ previews ~7~; ~RET~ copies the value. Calc syntax such as
  ~sqrt(9)~ and ~2^3~ works too. Prefix a number with ~=~ to calculate it: ~= 42~.
- ~g emacs~ searches Google. Selecting the ~g~ entry inserts ~g ~ first.
- ~https://example.org~ offers to open the URL if no tool matches.
- Any other input with no matches offers a web search.

* Settings worth knowing

Use ~M-x customize-group RET launcher RET~ to browse all options.

| Option                          | Purpose / default                                                   |
|---------------------------------+---------------------------------------------------------------------|
| ~launcher-app-discovery-method~ | ~spotlight~ by default; ~filesystem~ scans app directories directly |
| ~launcher-app-directories~      | App search roots; includes system and user Applications directories |
| ~launcher-tools~                | Your tools; includes Google (~g~) by default                        |
| ~launcher-fallback-search-url~  | Search URL when no tool matches; Google by default                  |
| ~launcher-show-icons~           | Show icons in graphical frames; ~t~                                 |
| ~launcher-builtin-icons~        | Optional icons for ~calculator~, ~search~ and ~url~; ~nil~          |

Use ~filesystem~ if Spotlight misses apps. Run ~launcher-refresh~ after changing
the search directories or discovery method, or adding or removing apps.
App icons are generated in the background and cached across Emacs restarts.

With ~nerd-icons~ loaded, configure calculator, search and URL icons:

#+begin_src emacs-lisp
(when (featurep 'nerd-icons)
  (setq launcher-builtin-icons
        `((calculator . ,(nerd-icons-faicon "nf-fa-calculator"))
          (search     . ,(nerd-icons-faicon "nf-fa-search"))
          (url        . ,(nerd-icons-faicon "nf-fa-link")))))
#+end_src

Search tools without their own icon use the shared search icon.

To remove the default Google tool:

#+begin_src emacs-lisp
(setq launcher-tools
      (cl-remove "g" launcher-tools :key #'car :test #'equal))
#+end_src

Configure tools after loading Launcher, in ~:config~ or
~(with-eval-after-load 'launcher ...)~. To save recent selections across restarts:

#+begin_src emacs-lisp
(with-eval-after-load 'savehist
  (add-to-list 'savehist-additional-variables 'launcher-selection-history))
(savehist-mode 1)
#+end_src

* Define a tool

A tool defines the results (candidates) to show and what to do when one is selected:

#+begin_src emacs-lisp
("prefix" :name "Tool name"
          :candidates my-candidates  ; List, or a function taking no arguments
          :query my-query           ; Function taking the query string
          :submit my-submit         ; Function taking the selected candidate
          :debounce 0.2             ; Optional delay for :query, in seconds
          :icon "...")              ; Optional icon, inherited by candidates
#+end_src

Use ~:candidates~, ~:query~, or both, and provide ~:submit~ to handle selections.
Prefixes must be unique and contain no whitespace. Use ~nil~ or ~""~ for a tool
that runs in general searches without a prefix.

Typing ~prefix text~ queries only that tool, passing ~text~ unchanged. Typing
~prefix ~ shows all static candidates without calling ~:query~.

| Property      | How it works                                                           |
|---------------+------------------------------------------------------------------------|
| ~:candidates~ | Loaded once per launcher session; titles filtered by completion styles |
| ~:query~      | Called as input changes; returns results without further filtering     |
| ~:submit~     | Runs when the user confirms a selection                                |
| ~:debounce~   | Delays dynamic queries; default 0. Queries still run synchronously     |
| ~:icon~       | Optional icon for the tool prefix and its candidates                   |

Each candidate is a property list (plist):

#+begin_src emacs-lisp
(:id unique-id :title "Visible title" :subtitle "Optional detail"
 :icon "..." :data value)
#+end_src

~:id~ must be stable, non-nil, and unique within each source. ~:title~ must be a
nonblank string. The other fields are optional; use ~:data~ for the action's
arguments. If both sources return the same ID, the dynamic candidate takes precedence.

Return ~nil~ from ~:submit~ after running an action. To display a result, return
a live buffer or ~(:buffer BUFFER :action ACTION)~ for custom ~pop-to-buffer~
behavior. The buffer opens after the minibuffer closes. Return ~(:input STRING)~
to replace the input and keep the launcher open.

Tools and candidates can set ~:icon~ to text, ~'(:file "/path/to/icon.png")~,
~'(:builtin search)~, or ~(launcher-icons-app "Finder")~ to reuse an indexed
app's icon. Candidates inherit the tool icon unless they specify their own.
No icon font is required; nerd-icons strings such as
~(nerd-icons-faicon "nf-fa-github")~ also work.

* Common tools

** Web search

Add a search tool with ~launcher-search-tool~. In the URL template, ~%s~ is
replaced with the URL-encoded query; ~%%~ inserts a literal percent sign.

#+begin_src emacs-lisp
(add-to-list 'launcher-tools
             (launcher-search-tool
              "gh" :name "GitHub"
              :url "https://github.com/search?q=%s"
              :icon (when (featurep 'nerd-icons)
                      (nerd-icons-faicon "nf-fa-github"))))
#+end_src

** Dictionary

Install ~osx-dictionary~ and add the configuration below. Type ~d word~ to preview
a definition, then press ~RET~ to see the full entry in another window. Press
~q~ to close the result window.

#+begin_src emacs-lisp
(use-package osx-dictionary
  :after launcher
  :config
  (defun my/dictionary-query (query)
    "Return a dictionary preview candidate for QUERY."
    (let ((word (string-trim query)))
      (unless (string-empty-p word)
        (require 'osx-dictionary)
        ;; Keep incremental queries out of the search history.
        (let* ((osx-dictionary-search-log-file nil)
               (text (with-temp-buffer
                       (osx-dictionary--insert-search-result word)
                       (buffer-string))))
          (list (list :id word :title word :data word
                      :subtitle
                      (truncate-string-to-width
                       (string-join (split-string text) " ")
                       160 nil nil "…")))))))

  (defun my/dictionary-submit (candidate)
    "Prepare CANDIDATE for display in a temporary dictionary window."
    (require 'osx-dictionary)
    (let ((word (plist-get candidate :data)))
      ;; Populate the native result buffer without keeping layout changes.
      (save-window-excursion
        (osx-dictionary--view-result word))
      (let ((buffer (osx-dictionary--get-buffer word)))
        (with-current-buffer buffer
          ;; Disable conflicting View mode keys.
          (when (bound-and-true-p view-mode)
            (view-mode -1))
          (use-local-map (copy-keymap (current-local-map)))
          (local-set-key (kbd "q") #'quit-window))
        (list :buffer buffer
              :action
              '((display-buffer-reuse-window display-buffer-pop-up-window)
                (inhibit-same-window . t))))))

  (add-to-list 'launcher-tools
               `("d" :name "Dictionary"
                 :icon ,(when (require 'nerd-icons nil t)
                          (nerd-icons-faicon "nf-fa-book"))
                 :query my/dictionary-query
                 :debounce 0.3
                 :submit my/dictionary-submit)))
#+end_src

** Choose from a list

For bookmarks, playlists, or mounted volumes, provide a list and use the selected
candidate's ~:data~ in your action. For example:

#+begin_src emacs-lisp
(defun my/bookmark-submit (candidate)
  (browse-url (plist-get candidate :data))
  nil)

(add-to-list 'launcher-tools
             '("fav" :name "Bookmarks"
               :candidates ((:id emacs :title "Emacs"
                             :data "https://www.gnu.org/software/emacs/")
                            (:id github :title "GitHub"
                             :data "https://github.com/"))
               :submit my/bookmark-submit))
#+end_src

Type ~fav ~ to list bookmarks or ~fav em~ to filter them. To load the list at
runtime, set ~:candidates~ to a function that takes no arguments.

** Run a command

Even a command with no arguments needs a candidate. For example:

#+begin_src emacs-lisp
(defun my/empty-trash-submit (_candidate)
  (when (yes-or-no-p "Empty Trash permanently? ")
    (start-process "empty-trash" nil "osascript" "-e"
                   "tell application \"Finder\" to empty the trash"))
  nil)

(add-to-list 'launcher-tools
             '("empty-trash" :name "Empty Trash"
               :candidates ((:id empty-trash :title "Empty Trash"
                             :subtitle "Permanently delete; confirmation required"))
               :submit my/empty-trash-submit))
#+end_src

** Show a live preview

Use ~:query~ when results depend on the current input. This tool previews
URL-encoded text and copies it on ~RET~:

#+begin_src emacs-lisp
(defun my/url-encode-query (query)
  (let ((encoded (url-hexify-string query)))
    (list (list :id 'encoded :title encoded
                :subtitle "Copy URL-encoded text" :data encoded))))

(defun my/url-encode-submit (candidate)
  (kill-new (plist-get candidate :data))
  nil)

(add-to-list 'launcher-tools
             '("encode" :name "URL Encode"
               :query my/url-encode-query :submit my/url-encode-submit))
#+end_src

Query functions should only produce candidates. Put actions such as copying,
launching, or deleting in ~:submit~. For slow queries, add ~:debounce 0.3~ to
reduce calls while typing.

* Use a global shortcut

To open Launcher from outside Emacs, use [[https://github.com/asmvik/skhd][skhd]] to bind a shortcut that calls
~emacsclient~. Start an Emacs server and define this wrapper to focus an active
minibuffer or open Launcher:

#+begin_src emacs-lisp
(require 'server)
(unless (server-running-p)
  (server-start))

(defun my/launcher ()
  "Focus the active minibuffer or open Launcher."
  (interactive)
  (run-at-time
   0 nil
   (lambda ()
     (condition-case nil
         (if-let* ((win (active-minibuffer-window)))
             (select-frame-set-input-focus (window-frame win))
           (select-frame-set-input-focus (selected-frame))
           (call-interactively #'launcher))
       (quit nil)))))
#+end_src

Add this ~Alt-Escape~ binding to =~/.skhdrc=. Adjust the ~emacsclient~ path and
server socket path to match your installation:

#+begin_src conf
alt - escape : /opt/homebrew/bin/emacsclient -s "$(/usr/bin/getconf DARWIN_USER_TEMP_DIR)emacs$(/usr/bin/id -u)/server" -e '(my/launcher)' 2>/dev/null || /usr/bin/open -a Emacs
#+end_src

You can also use [[https://github.com/xiaoxinghu/m-x][M-x.app]] to invoke Emacs from a global shortcut.
